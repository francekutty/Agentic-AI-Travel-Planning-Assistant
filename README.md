
# Agentic AI-Based Travel Planning Assistant Using LangChain

## Project Overview
An AI-powered travel planning assistant that generates personalized travel itineraries using flights, hotels, tourist attractions, weather information, and budget estimation.

## Objectives
- Flight search and recommendation
- Hotel recommendation
- Tourist places discovery
- Real-time weather integration
- Travel budget estimation
- Agentic AI-based itinerary generation

## Technologies
- Python
- LangChain
- Large Language Models (LLMs)
- Open-Meteo API
- Streamlit
- JSON

## Project Status
Development in progress.
